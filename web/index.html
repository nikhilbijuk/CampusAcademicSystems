KTU Mini Project Viva & Architecture Guide

Quick cheat sheet explaining how Java OOP concepts are implemented across this codebase.

Polymorphism

Dynamic Tariff & Meal Costs

BaseRoom and MealPlan are abstract classes. ACSuite and SingleOccupancy override calculateMonthlyTariff(), while StandardPlan and SpecialDietPlan override calculateMealCost(). The billing routine calls them polymorphically at runtime.

Inheritance

Role-Based Quotas

User is the superclass. Student (quota 2), Faculty (quota 5), and Coach (quota 10) extend User and provide their own limit via overridden getBookingLimit().

Custom Exceptions

Business Rule Integrity

Enforces invariants: SlotAlreadyBookedException prevents double bookings, OutstandingFineException freezes bookings, BookingQuotaExceededException caps reservations, and InvalidLeaveDaysException rejects negative or month-exceeding days.

Persistence

Native Java Object Serialization

All models implement Serializable. CampusStorageManager uses ObjectOutputStream and ObjectInputStream to automatically persist and reload full state to/from data/campus_data.ser.
